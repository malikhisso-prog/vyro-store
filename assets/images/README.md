

\# VYRO® Image Assets



Place the store's image files in this directory.



\## Recommended Structure



```text

assets/

└── images/

&#x20;   ├── logo.svg

&#x20;   ├── favicon.png

&#x20;   ├── hero-sneaker.webp

&#x20;   ├── about-store.webp

&#x20;   └── products/

&#x20;       ├── air-phantom-x.webp

&#x20;       ├── street-runner-90.webp

&#x20;       ├── night-pulse.webp

&#x20;       ├── motion-edge.webp

&#x20;       ├── velocity-pro.webp

&#x20;       └── urban-flex.webp

```



\## Image Guidelines



\- Use WebP format whenever possible.

\- Use high-resolution product photography.

\- Keep product images consistent in size and background.

\- Compress images before uploading.

\- Use descriptive, lowercase filenames.

\- Only use images you own or have permission to use.



\## Suggested Dimensions



\- Product images: 1200 × 1200 px

\- Hero images: 1920 × 1000 px

\- About images: 1200 × 900 px

\- Logo: SVG format
